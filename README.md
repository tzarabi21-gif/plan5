# NEXA
سامانه برنامه‌ریزی و مدیریت مطالعه با رابط تیره نئونی، ورود کاربران، داشبورد، پنل مدیریت، مدیریت صفحات و تنظیمات API.

## نسخه‌ها
- `NEXA-XAMPP`: اجرای محلی با PHP 8.2+ و MySQL/MariaDB
- `NEXA-RENDER`: استقرار کانتینری روی Render (نیازمند MySQL مدیریت‌شده یا سرویس DB سازگار)
- `NEXA-LIARA`: استقرار کانتینری روی لیارا (نیازمند دیتابیس MySQL)

## شروع سریع XAMPP
1. پوشه `NEXA-XAMPP` را داخل `htdocs` کپی کنید.
2. Apache و MySQL را روشن کنید.
3. در phpMyAdmin یک دیتابیس با نام `nexa` بسازید.
4. فایل `config.php` را با اطلاعات دیتابیس خود تنظیم کنید.
5. آدرس `http://localhost/NEXA-XAMPP/install.php` را باز کنید.
6. پس از نصب، `install.php` را حذف یا دسترسی آن را مسدود کنید.
7. وارد `/` شوید و از بخش مدیریت، رمز مدیر و کلیدهای API را تنظیم کنید.

## استقرار
در هر پوشه استقرار، متغیرهای `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASS`, `APP_URL` را تنظیم کنید. از دیسک/دیتابیس پایدار استفاده کنید. فایل‌های آپلودی روی filesystem موقت کانتینر نگهداری نشوند؛ برای تولید، object storage اضافه کنید.

## امنیت مهم
- کلیدهای API فقط در جدول تنظیمات سمت سرور ذخیره می‌شوند و در رابط عمومی نمایش داده نمی‌شوند.
- برای محیط واقعی حتماً HTTPS، رمز قوی مدیر، محدودیت نرخ ورود، SMTP/SMS واقعی، بکاپ و سیاست حریم خصوصی تنظیم شود.
- پیامک کاوه‌نگار و پرداخت در این نسخه دارای محل تنظیم و ساختار اتصال هستند؛ ارسال/پرداخت واقعی تا واردکردن کلید معتبر و پیاده‌سازی/تأیید قرارداد سرویس فعال نمی‌شود.
- دستیار هوش مصنوعی دارای محل ثبت چند ارائه‌دهنده و تست اتصال پایه است؛ کلیدها را فقط در پنل مدیر وارد کنید.
